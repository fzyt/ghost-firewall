## 一、本轮改了什么

用户对第四版的反馈是**「整套视觉语言不对：想换风格」**，并对文案提了 5 条具体意见。
本轮把 9 段的画面全部推翻重做成**终端代码风**，同时重写文案与分段时长。

| 改什么 | 做法 |
|---|---|
| 视觉语言整套换掉 | 新增共享模块 `terminal.js`（终端窗口 / 逐字打出 / 闪烁光标 / 段头 HUD / 进度条）；9 段页面全部重写 |
| 旧动效基建退役 | `motion.js`（粒子 / 流光 / 视差 / 逐字入场）本轮不再被任何页面引用，文件保留未删 |
| 文案重写 | 旁白 9 段全部重写；画面文案从「插画 + 标题」改成终端里的命令与输出 |
| 分段时长重排 | 21/14/25/26/18/16/21/18/20（合计仍 180s），配乐 `score.py` 的 SECTIONS 同步 |
| 语音重合成 | edge-tts `zh-CN-YunxiNeural`，synth-voice.py 增加失败重试 |

### 1.2 九段的终端内容

| 段 | 时长 | 终端里演什么 |

- **旁白稿与成片不是同一版**：本成片用的是本文件里记录的 9 段旁白；`03-文档/旁白稿-180s.md` 已同步更新（实测时长与语速已回填）。

## 四、复现命令

```bash
# 本机：静态体检 + 全片自检
cd "01-代码/推广视频工程"
node check-imports.mjs && node check-fonts.mjs && node selfcheck-all.mjs

# 本机：合成旁白（需要外网）
python3 synth-voice.py --script ../../03-文档/旁白稿-180s.md --out audio/voice \
  --edge-tts /home/kirito/main/tmp/tts-venv/bin/edge-tts --voice zh-CN-YunxiNeural

# 同步到 do 后：配乐 → 全量渲染 → 混音 → 拼接 → 质检
ssh do "source '/home/kirito/main/项目/纯代码视频制作/01-代码/环境.sh' && cd '<DO工程目录>' && \
  python3 score.py --out audio/score-180s.wav && node render-all.mjs && \
  python3 mix-voice.py --manifest audio/voice/manifest.json --voice-dir audio/voice \
    --music audio/score-180s.wav --out audio/mix-voice-180s.wav && \
  bash concat-and-encode.sh segments.txt audio/mix-voice-180s.wav \
    'out/Ghost-Firewall-推广视频-180s-终端风版.mp4' 180 30 && \
  bash qc.sh 'out/Ghost-Firewall-推广视频-180s-终端风版.mp4' ../../05-媒体"
```

### 踩坑

- **`synth-voice.py` 会被外网抖动打断**：edge-tts 偶发 `NoAudioReceived`，整条流水线当场退出。已加 3 次重试（间隔递增）。
- **写页面时 `duration` 不能写死**：旧 s04 把段长写死成 26，时间轴一改就自检失败。段长统一走 `createSegment()` 读 URL 参数。
- **`check-fonts.mjs` 只扫 `segments/*.html`**：共享模块里的字体名扫不到，所以每个页面自己留一条带引号的字体栈字面量。
- **`terminal.js` 的中文行要放大一号**：Noto Sans SC 同字号比 JetBrains Mono 视觉偏小，混排时中文行用 26px、英文行 24px。
