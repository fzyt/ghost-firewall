## 一、本轮改了什么

用户看完第三版后提了两条：**「动画效果不太好，重新做一份动画效果」** + **「全局带语音讲解」**。
本轮按这两条重做了全部 9 段的动效，并给全片加了中文旁白。

| 改什么 | 做法 |
|---|---|
| 动效语言统一升级 | 新增共享模块 `motion.js`：粒子背景 / 流光扫描 / 边缘流光 / 视差层次 / 逐字入场，9 段全部接入 |
| 全片旁白 | 新增 `synth-voice.py`（合成）+ `mix-voice.py`（混音），音色 edge-tts `zh-CN-YunxiNeural` 男声 |
| 守卫加严 | `selfcheck-all.mjs` 的「禁用 API」扫描扩展到共享模块（common.js / themes.js / motion.js） |

### 1.1 动效基建：`motion.js`

| 导出 | 作用 | 用在哪 |
|---|---|---|
| `drawParticleField` | 三层深度的光点背景，层间速度不同 ⇒ 天然视差 | 9 段全部（每段不同种子与色调） |
| `drawLightSweep` | 斜着扫过区域的光带（柔带 + 亮芯），两端淡出循环不突兀 | 全片一层极淡的 + 终端/窗口内一层 |
| `drawEdgeSweep` | 一道亮线沿卡片上沿来回跑 | 入口卡、服务卡、保险卡、阶梯卡、窗框、门框、品牌细线 |
| `parallax` / `withParallax` | 按深度给内容位移与缩放（镜头推进 + 横向漂移） | s01 左图、s02 主体、s03 门与剪影、s04 阶梯、s05 节点与扇出、s06 时间轴 |
| `kineticText` | 逐字错开落位（首句上滑 + 回弹） | s09 收尾两行 tagline |
| `breathe` | 状态点的明暗呼吸 | s07 面板当前页 |

约束照旧：**画面必须是 t 的纯函数**。粒子初始位置用 `hash01`（按序号播种）而不是 `Math.random`，
所以同一 t 永远同一帧 —— `selfcheck-all.mjs` 的「同 t 像素一致」9/9 通过就是证据。

> 踩坑：`withParallax` 最初写成「只有 scale≠1 才回中平移」，
> 结果 scale=1 时内容整体偏移了 (960,540)，整段画面被推出画布。
> 现在平移恒已成对（先移到中心、画完移回来）。

### 1.3 配音

- **音色**：edge-tts `zh-CN-YunxiNeural`（男声，技术讲解腔），需要外网。
- **文案真相源**：`03-文档/旁白稿-180s.md`，`synth-voice.py` 直接读它的引用行 —— 改稿重跑脚本即可。
- **语速自动贴合**：脚本先按自然语速合成一次，读字幕末尾时间戳得到真实长度，
  再按比例反推需要的语速重合成（最多三轮，夹在 -25% ~ +40%）。
- **实际结果**（每段语音都收在本段内，无跨段重叠）：

| 段 | 段长 | 语音长度 | 合成语速 |
|---|---|---|---|
| s01 | 14s | 13.16s | +19% |
| s02 | 16s | 15.28s | -10% |
| s03 | 22s | 21.21s | -4% |
| s04 | 26s | 25.23s | +9% |
| s05 | 20s | 19.11s | -4% |
| s06 | 22s | 21.21s | +22% |
| s07 | 28s | 27.26s | +10% |
| s08 | 14s | 13.21s | +28% |
| s09 | 18s | 17.51s | +0% |

- **混音**：`mix-voice.py` 把 9 段按起点延迟到位 → 混成一条 → 统一响度（-16 LUFS）→
  配乐以旁白为侧链做闪避（ducking，threshold 0.02 / ratio 8 / attack 12ms / release 320ms）→ 限幅 0.95。
- **闪避实测**（按窗口量 RMS）：

| 窗口 | 原始配乐 | 混音后 | 差 |
|---|---|---|---|
| 段间留白 13.3–13.9s | -28.3 dBFS | -28.5 dBFS | -0.2 dB（无人声时配乐完全恢复） |
| 配乐段落 100–104s | -17.3 dBFS | -17.8 dBFS | -0.6 dB |
| 有人声 0–2s | -25.5 dBFS | -15.3 dBFS | +10.2 dB |

### 1.4 为让旁白塞进段落，改了两处文案

## 四、踩坑

| 现象 | 根因 | 修法 |
|---|---|---|
| 整段画面被推出画布 | `withParallax` 的回中平移写在了 `scale !== 1` 分支里 | 平移恒已成对：先移到中心、画完移回来 |
| edge-tts 报 `--rate: expected one argument` | 负语速（如 -20%）被 argparse 当成选项 | 改用 `--rate=-20%` 等号形式 |
| ffmpeg 报 `Stream specifier 'voice' matches no streams` | 同一条旁白被用了两次（侧链 + 混音） | 中间加 `asplit=2` 分成两路 |
| 共享模块扫描误报 | common.js 的注释里写了 `Date.now(), Math.random()`，文档警告本身命中正则 | 改写注释（守卫不放宽） |

## 五、未验证与风险

- **没有真人试听**：音色是 edge-tts 的合成男声，不是真人配音；用户若要换音色，
  只需重跑 `synth-voice.py`（换 `--voice`）+ `mix-voice.py`，**不用重渲画面**。
- 配音版与原版**并存**：原版 `Ghost-Firewall-推广视频-180s.mp4` 未删除。
- s01 语速 +19%、s08 +28%：都已接近「讲解视频」的上限（自然朗读 4–5 字/秒），再快就会显得赶。
- 闪避是 ffmpeg 的 `sidechaincompress`（静态参数），不是逐字级别的 ducking；
  人声与配乐同时爆发的瞬间可能有轻微不齐。
- 片段渲染在 do 上跑，本机只做静帧与自检；两端都是 playwright-core 1.65.1 + chromium-1255，
  静帧与成片同源，但**未做两端成片逐帧比对**。
- s07 的面板仍是**示意图**（侧栏用 README 的 13 个模块名，表格里的规则与证书是示意的）。
- 视频中出现的 IP `198.51.100.24` / `192.168.1.1` 均为文档/默认保留地址。
- `fonts/` 未入库；换机器重渲需先从 `纯代码视频制作/01-代码/fonts/` 复制过去。
